## 02.11.2026 — товароучёт, шаг 2: приход от поставщика
- «Склад» у собственника разделён на «Товары» и «Документы». В «Документах» —
  список за месяц (фильтр по виду), кнопка «+ Приход».
- Приход: дата, куда («Наш склад» / «Ответхранение»), поставщик (подсказки из прошлых
  приходов), № накладной (для ответхранения — № акта МХ-1), комментарий.
  Товар добавляется сканером (штрихкод + Enter; повторный скан даёт +1) или поиском
  по словам. Закупка подставляется по последнему приходу, рядом цена продажи
  (меняет цену в карточке при проведении) с наценкой; «ниже закупки!» при минусе.
  «+ Новая карточка» — для товара, которого нет в каталоге.
- Черновик правится свободно. «Провести» требует закупку > 0 (для нашего склада)
  и количество > 0. Проведённый — только «Отменить проведение» с обязательной
  причиной (кто, когда, почему пишется в документ); если остаток уйдёт в минус,
  система предупреждает и просит подтвердить. «Создать копию» — исправленный приход.
  Цена продажи при отмене назад не возвращается (меняется в карточке товара).
- Ответхранение: отдельный склад, в стоимость нашего склада не входит; в «Товарах»
  переключатель «Наш склад / Ответхранение поставщика», в карточке товара
  «+ N на ответхранении». Цена в приходе — оценка поставщика (для будущих 5%).
- Карточка товара: «Изменить цену» (собственник).
- Сотрудник документов не видит; сервер отказывает ему в docs/doc/partners/prod_find,
  закупка и поставщик в движении товара ему не отдаются.
- Проверено: приход 2 шт. по 4 000 к 4 шт. по 4 156 → 6 шт., средняя 4 104;
  отмена → снова 4 шт. по 4 156; ответхранение 8 шт. не трогает наш склад.

## 02.11.2026 — товароучёт, шаг 3: продажа, возврат, выдача с ответхранения
- В «Документах»: «+ Продажа», «+ Приход», «+ Возврат», «+ Выдача с ответхранения»;
  итоги месяца по проведённым: продажи (минус возвраты), прибыль и % от продаж,
  скидки, приход по закупке, выдано с ответхранения и сколько из этого магазину.
- Продажа: телефон покупателя (необязательно; знакомый — имя подставится, новый —
  попадёт в «Клиенты»), имя/организация, оплата (наличные/карта/перевод/безнал).
  Товар — сканером или поиском, цена из карточки; если цену снизить — видно
  «по прайсу … · скидка …%», «ниже себестоимости!». Прибыль до проведения — оценка
  по средней себестоимости, после — точная. Себестоимость продажи = средняя на момент
  проведения. Если по учёту товара не хватает — предупреждение и «Провести всё равно».
  В карточке товара у собственника кнопка «Продать».
- Возврат: из проведённой продажи кнопкой «Оформить возврат» (себестоимость
  возвращается та же, что была в продаже; больше проданного не вернуть, учитываются
  прошлые возвраты) или отдельно. Продажу с проведённым возвратом отменить нельзя,
  пока не отменён возврат.
- Выдача с ответхранения (уточнено Ильёй 02.11): товар просто убирается со склада
  ответхранения — только количество, без денег. Бонус 5% поставщик начисляет в своём
  кабинете; отдельно его не учитываем — он сам отразится в закупочной цене прихода,
  когда Илья им воспользуется (вносит цены по накладной).
- Продажи пока ведёт только собственник; сотруднику документы недоступны.
- Чек по-прежнему пробивается на Эвоторе; сверка с ofd.ru — позже.
- Проверено: продажа 2 шт. по 5 300 (прайс 5 590) → скидка 580, прибыль 2 288;
  возврат 1 шт. → остаток 3; повторный возврат 2 шт. отклонён; выдача 3 шт. с
  ответхранения → остаток ответхранения уменьшился, наш склад не тронут.

## 02.11.2026 — загрузка документов поставщиков
- Код для опознания товара: главный — артикул производителя (CAE), он же «Артикул»
  в CloudShop (заполнен у 1 863 карточек; у Пауэра T-коды Ikon и CAE Fortune/Sailun —
  это он). Второй — запомненный код поставщика (таблица supcodes: поставщик + код →
  карточка, пишется при каждой загрузке). Третий — штрихкод (в документах его нет,
  нужен для сканера). Последний — по названию (размер шины / параметры диска + слова).
- «Загрузить документ (PDF / XML)» в Закупках, Выдаче и Итогах месяца: PDF из Диадока
  читается в браузере (lib/pdf.min.js — PDF.js 3.11.174 legacy, Apache-2.0; запас —
  jsdelivr), таблица разбирается по строке номеров граф (УПД: А,1,1а…; акты МХ: 1…10).
  Виды: УПД/счёт-фактура → приход на наш склад; акт МХ-1 → приход на ответхранение;
