# Учёт ВладАвтоШины

Своя товароучётная система шинного центра IVANOR (ИП Нефедов И. А.,
Владимир, ул. Ноябрьская, 129) на замену CloudShop.

Перед работой прочитай `docs/STATUS.md` (где остановились) и `docs/TZ.md`
(решения и план). В конце шага обнови `docs/STATUS.md`.

## Владелец

Илья — собственник, не программист. Объяснять по-русски, простыми словами,
без жаргона. Каждый шаг заканчивать тем, что можно открыть и проверить руками.

## Правила, которые не нарушаем

- Себестоимость, закупочные цены, прибыль и маржа не попадают ни в витрину,
  ни в интерфейс роли «сотрудник».
- Выгрузки CloudShop (`*.xlsx`, `*.csv`) не коммитим — в них себестоимость.
- Остаток считается из движений, а не хранится числом в карточке.
- Проведённые документы не редактируются молча.

## Стек

С 02.11.2026: PHP 7.4 + SQLite на хостинге Джино (vladautoshina.ru/montazh/), одна
страница `index.html` + `api.php`. Так уже работает пульт шиномонтажа; товароучёт
строится в том же приложении (вкладка «Склад»), с тем же входом по PIN.
Код должен работать на PHP 7.4 и старой SQLite (без UPSERT `ON CONFLICT`,
без `json_extract`); кириллицу без учёта регистра сравнивать в PHP, не в SQL.
Excel в браузере читается через `lib/xlsx.full.min.js` (SheetJS 0.18.5, Apache-2.0).

## Структура

- `docs/` — ТЗ и статус.
- `vitrina/` — прототип витрины из выгрузки каталога CloudShop.
- `montazh-site/` — рабочее приложение на хостинге: пульт шиномонтажа и склад.
- `montazh-site/hotel/` — шинный отель (перенесён с sklad.shinhotel33.ru) внутри пульта:
  работает с той же базой `sklad.db` и папкой `uploads` старого адреса (путь ищет
  `hotel_path.php`, можно задать `hotel_dir` в config.php), вход — по сессии пульта.
- `kp/` — генератор КП (vladautoshina.ru/kp/); пускает собственника пульта без пароля.
  `nastroyki.php`, `data/`, `foto-kp/`, подпись и печать не коммитим.
- `montazh/` — первый прототип пульта (артефакт), больше не используется.
